# Product Searcher — Project Context

## Overview
Flutter app. Single feature implemented: **auth**. Future features will include product search.

## Tech Stack
- Flutter + Dart (SDK ^3.11.1)
- Firebase (firebase_core ^4.6.0, firebase_auth ^6.3.0)
- Google Sign-In **7.2.0** — uses new singleton API (`GoogleSignIn.instance`, `.initialize()`, `.authenticate()`)
- State management: **Riverpod 3.x** (`flutter_riverpod ^3.3.1`)
- Functional error handling: **dartz** (`Either<Failure, T>`)
- Value equality: **equatable** (`equatable ^2.0.7`) — `Failure` extends `Equatable`, removes manual `==`/`hashCode`
- Immutable models/states: **freezed** + **json_serializable** (code-gen via build_runner)
- Testing: mocktail

## Key Implementation Notes
- Google Sign-In 7.2.0 breaking changes: `GoogleSignIn.instance.initialize()` must be called before `authenticate()`. `authenticate()` throws `GoogleSignInException` on cancel. `idToken` only (no `accessToken`) for Firebase credential.
- `AuthRepositoryImpl` maps `FirebaseAuthException` → `AuthFailure`, generic `Exception` → `GoogleSignInFailure` or `ServerFailure`.
- `AuthNotifier.build()` calls `getCurrentUser()` synchronously to hydrate state on startup.
- Freezed `.freezed.dart` and `.g.dart` files are generated — run `dart run build_runner build` after model changes.
- Theme: adaptive (Material for Android, Cupertino-style widgets in presentation layer). Cupertino text themes (`lightCupertinoTextTheme` / `darkCupertinoTextTheme`) are defined in `AppTextStyles` and consumed by `AppTheme.cupertinoLight` / `cupertinoDark`.

## Key Widgets
- `auth_illustration.dart`: Animated lock illustration (float + glow pulse, `TickerProviderStateMixin`). Used in `auth_header.dart`.
- `google_sign_in_button.dart`: Uses `flutter_svg ^2.0.10+1` with the official Google G SVG embedded as a string constant (`_kGoogleLogoSvg`). `flutter_signin_button` was removed — incompatible with `font_awesome_flutter` v11 (`FaIconData` no longer extends `IconData`).
- Password validation in `register_screen.dart`: ≥8 chars, uppercase, digit, special char (`[!@#$%^&*()\-_=+\[\]{};:,.<>?/\\|~]`).
